# Crew-Travel-Planner-Agent-
Built an AI-powered Travel Planner using Python and CrewAI. The user enters a city name, and a single Travel Planner agent recommends exactly three real, well-known places to visit, each with a brief description and a practical visiting tip. The agent’s role, goal and backstory are aimed at first-time visitors with limited time, and the task’s expected output defines a strict three-line format so the results come back concise and consistent. The agent and task are assembled into a Crew and run with crew.kickoff(), with the city passed in as a dynamic input. The OpenAI model (gpt-4o-mini) is configured through CrewAI’s LLM class, and the API key is loaded securely from a .env file using python-dotenv, never hard-coded.
